# Multi-Primers_Analyser
A software for analysing multiple primers simultaneously.
#### Video Demo:  <https://youtu.be/QFTo61_j3w0>
#### Description:
The Multi primers analyser (multi_pa) is a Python program that analyses self- and hetero-dimers of multiple oligonucleotides (or primers) at the same time. The oligonucleotide can be any degenerate and non-degenerate DNA or RNA sequence.

Given a list of sequences, the software analyses all possible combinations of primer pairs. 

Matches of self and hetero-dimers with more than 2 consecutive matches are displayed and results are summarised in a table.

Once the analysis is complete, the user is given the option to continue the analysis by adding more primers or to end it. By continuing the analysis, more primers will be added to the existing list and all primers will be analysed against themselves (self-dimer) and each other (hetero-dimer).
If the user chooses not to progress further, the list is deleted.

This software is intended as an aid to develop multiplex NAAT(Nucleic Acid Amplification Test)-based assays.

The user is prompted for:
a valid number of primers (positive integers only)
a valid name (unique and not empty)
a valid sequence (according to the IUPAC nucleotide code and not empty)

multi_pa.py software requires Bio.SeqUtils, colorama, cs50, itertools, re and tabulate libraries, plus a custom library generated for this software called degenerate_primer. 
multi_pa.py contains the following functions:

- get_pos_int(prompt)
An infinite while loop combined with the if statement instead of a try conditional to capture all the possible invalid integers (decimals, negative and zero) in less lines of coding.

- multi_pa()
The software is abstracted away in a function, so it can be re-run by the user multiple times. This function calls several functions from the degenerate_primer.py library.

degenerate_primer.py library.
degenerate_primer.py is a library of functions required for multi_pa.py to work, so that the main software file is not overcrowded and kept clean. The functions are:

- degenerate_primer_combinations(string, dictionary)
A function that generates all possible sequence combinations for a degenerate primer, where one character can be replaced with multiple nucleotides. This function requires the “IUPAC code for nucleotides” dictionary, generated inside the library itself.

- calculate_degenerate_tm(list, na_conc=50.0, mg_conc=0.0)
A function that calculates min, max, and average Tm for a primers pool (useful for all degenerate primers combinations). This function requires the MeltingTemp function imported as mt from Bio.SeqUtils library.

-rev_st(string)
A function that reverse the characters in a string. I find it more intuitive to have a self-explanatory function rather than [::-1] each time.

- deg_self_dimer(string)
A function that given a sequence of DNA or RNA, compares each nucleotide base, shifting the reverse of the sequence one base a time to the right. Total matches found are saved in a score variable which is added to a list of scores.

- self_dimer_check(list1, list2, string)
A function that checks self dimers and print only those with matches =>3 in a row.

- hetero_dimer_check(list1, list2, string1, string2)
A function that checks hetero dimers and print only those with matches =>3 in a row.

- print_matches2(string, int)
A function that prints "|" characters to visualise matches in all self-dimers (degenerate and non).

- self_matches2(string, int)
A function that assigns "|" characters to matches found in all self-dimers (degenerate and non). This function is not used for displaying matches as print_matches2 does, but returns the number of total dimers found with 3 or more consecutive "|" characters or matches, which can be of concern. I had to implement an additional function to solve the layout and spacing issues generated by the print_matches2 function in case no matches were found.

- print_hetero_matches2(string, string, int)
A function that prints "|" characters to visualise matches in all hetero-dimers (degenerate and non). This function is the equivalent of the print_matches2 function for two strings that could be different in length. To capture the error and bypass it I chose the try and IndexError strategy.

- hetero_matches2(string, string, int)
A function that assigns "|" characters to matches found in hetero-dimers (degenerate and non). This function is not used for displaying matches as print_hetero_matches2 does, but returns the number of total dimers found with 3 or more consecutive "|" characters or matches, which can be of concern. I had to implement an additional function to solve the layout and spacing issues generated by the print_hetero_matches2 function in case no matches were found.

- get_index2(list)
A function that generates a list of numbers, each representing the nucleotide's index at which at least one match with the other sequence (self-dimer or hetero-dimer) has been found. This function will allow for the correct alignment of matching bases in the self_dimer_check and hetero_dimer_check functions.

- deg_hetero_dimer2(string, string)
A function that given two sequences of DNA or RNA, compares each nucleotide base, shifting the second sequence one base a time to the right. Total matches found are saved in a score variable which is added to a list of scores. Then, it compares each nucleotide base, shifting the second sequence one base a time to the left. Total matches found are saved in a score variable which is added to a second list of scores. This function takes into account the possible difference in length of the two sequences.
